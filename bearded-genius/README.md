# Bearded Genius

A separate Bearded Genius website/codebase built from the brand's Instagram archive. It is intentionally separate from Lagos Sneaker Club and contains no LSC copy, routes, or assets in the live UI.

## Run

```bash
npm install
npm run dev
npm run build
```

## What this includes

- Vite + React + TypeScript storefront
- Bearded Genius profile image as logo
- Curated Instagram assets arranged under `public/assets/bearded-genius/`
- Product/reserve cards for Afri Jorts, Button-Up, Custom Threads, and Statement Set
- WhatsApp reserve drawer using `+234 909 943 6487`
- Editorial culture/gallery sections
- Raw Instagram archive kept under `public/assets/bearded-genius/reference/raw-instagram`
- Claude/Relume prompt in `CLAUDE_RELUME_PROMPT.md`

## Notes

Some raw Instagram reference posts mention Lagos Sneaker Club collaborations/events. They are kept only as reference source material and are not used in the live Bearded Genius UI.
