# Lagos Sneaker Club Claude + Relume Kit

This folder is an LSC-only handoff kit. Do not use Bearded Genius as a website brand, nav item, page, or product line.

## Files

- `PROMPT_FOR_CLAUDE.md` - detailed prompt to paste into Claude.
- `START_FULL_DEV_IN_CLAUDE.md` - exact starter prompt to paste into Claude before the full build.
- `RELUME_SITEMAP_PROMPT.txt` - shorter prompt to paste into Relume Site Builder.
- `ASSET_MANIFEST.md` - local images and videos arranged by use.
- `RESEARCH_NOTES.md` - source-backed notes used to shape the prompt.
- `assets/logo` - Lagos Sneaker Club logo.
- `assets/images/brand` - dark editorial brand/store graphics.
- `assets/images/events` - events, store partnership, and community images.
- `assets/images/products` - sneaker/product/lifestyle images.
- `assets/videos` - public Instagram clips for slideshow and motion sections.

## Recommended Workflow

1. Upload or attach this full folder to Claude.
2. Paste `START_FULL_DEV_IN_CLAUDE.md` into Claude.
3. Ask Claude to first produce the final concise Relume prompt, sitemap, and page-section plan.
4. Paste `RELUME_SITEMAP_PROMPT.txt` into Relume Site Builder as the starting prompt.
5. In Relume, generate the sitemap, edit section names/descriptions, then generate wireframes.
6. Use Relume Style Guide / Design View for the base visual system.
7. Export to Figma, Webflow, or React for custom animation, slideshow, video handling, and ecommerce details.
