## Research-Backed Design System Requirements

Apply these references as implementation constraints:

- **Relume / Claude Design**: work design-system-first. Define colours, typography, spacing, buttons, cards, quote forms, process timeline, media modules, mobile nav, and focus states before building pages. Use the downloaded logo/media as brand inputs. The output should feel intentionally branded, not like a default template.
- **Emil Kowalski practical animation principles**: motion must have a job. Use transform and opacity, origin-aware menus/sheets, short UI timings, custom easing, and slow-motion review. Button press should be subtle (`scale(.97)`). Do not animate from `scale(0)`; start around `.9` or higher. UI enters should feel responsive with ease-out curves; exits can be quicker with ease-in. Most UI motion should stay under 300ms, while drawers/sheets can use a slower native-feeling curve.
- **Drawer / sheet motion**: for mobile menus, quote drawers, filter panels, and modals, use `transform 0.5s cubic-bezier(0.32, 0.72, 0, 1)` or the tokenized equivalent. Handle mobile viewport/keyboard issues so forms do not become hidden.
- **Remotion official guidance**: if creating programmatic videos/reels, drive animation from `useCurrentFrame()` and `useVideoConfig()`, map values with `interpolate()`, use explicit frame ranges, `Easing.bezier`, `Sequence`, and Remotion asset APIs (`staticFile()`, `<Img>`, `<Video>` / `@remotion/media`). Do not use CSS/Tailwind animations inside Remotion compositions.
- **Website video guidance**: normal site videos should be HTML5 video components with poster images, muted autoplay by default, lazy/in-view playback, visible mute/unmute controls, and a single-source audio system so only one video can be audible at a time.
