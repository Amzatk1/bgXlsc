# World-Class Reference Brief: The Factory Nigeria

This brief gives Claude a higher creative bar for The Factory Nigeria. Use these references as strategy, interaction, and quality inspiration only. Do not copy layouts, typography, animations, imagery, copy, or brand systems.

## Core Positioning

The Factory Nigeria is not a normal retail shop. Treat it as **quote-commerce for custom garment production and printing**: a conversion website that behaves with ecommerce clarity, but sells production confidence, service packages, process transparency, and WhatsApp enquiries.

Create a completely new direction from Lagos Sneaker Club and Bearded Genius:

- **Concept name:** Factory OS / Production Desk.
- **Main visual model:** production dashboard + atelier + quote console.
- **Core UI objects:** order tickets, service cards, production-board rows, status chips, media proof wall, appointment panel, print-method selector, quote-builder drawer.
- **Primary conversion:** request a WhatsApp quote, not a fake cart checkout.
- **Hero feeling:** busy Lagos garment production, clean operational confidence, real hands/process media, clear MOQ and address.

## Awarded / Highly Rated Reference Sources

Use these sources to set the design quality bar:

1. **Awwwards E-commerce collection**: study contemporary online-store patterns, product/media staging, category pages, interaction design, and creative commerce execution. Source: https://www.awwwards.com/websites/e-commerce/
2. **Awwwards Ecommerce of the Year winners**: use as historical high-bar examples of awarded ecommerce craft. Notable winners include Nixon eCommerce Platform, Protest Sportswear, Simply Chocolate, Frans Hals Museum, MA, Mammut Expedition Baikal, and Pangram Pangram Foundry. Source reviewed: https://fr.wikipedia.org/wiki/Awwwards

4. **Baymard ecommerce UX research**: use for conversion fundamentals, mobile clarity, forms, product/service discovery, search/filter mental models, and checkout-like quote flow. Baymard cites 200,000+ hours of UX research, 700+ guidelines, and 18,000+ design examples. Source: https://baymard.com/research
5. **Relume / Claude Design**: use a design-system-first workflow so colours, typography, spacing, components, and media are consistent before implementation. Sources: https://www.relume.io/claude-design-export and https://www.relume.io/style-guide
6. **Emil Kowalski motion writing**: use purposeful, natural UI motion with origin-aware transitions, short timings, custom easing, subtle button press, and reduced-motion support. Sources: https://emilkowal.ski/ui/7-practical-animation-tips and https://emilkowal.ski/ui/good-vs-great-animations
7. **Remotion official docs**: use only if creating optional exportable video/reel compositions. Website UI motion should remain normal frontend motion. Sources: https://www.remotion.dev/docs/use-current-frame and https://www.remotion.dev/docs/interpolate

## Specific Ecommerce / Quote-Commerce Patterns To Synthesize

- **Awwwards-style creative commerce:** large media moments, distinct art direction, smooth transitions, editorial product/service storytelling.
- **Baymard-style usability:** obvious CTAs, clear service labels, clean forms, predictable navigation, accessible mobile tap targets, no hidden critical information.
- **Fashion/apparel commerce clarity:** service cards should communicate garment type, MOQ, customization path, artwork requirements, and next action without forcing users to read long text.
- **B2B service flow:** every page should answer: What can they make? What do I need to send? What is the minimum quantity? Where are they? How do I start?
- **Checkout-inspired quote builder:** the quote flow should feel as simple as checkout, but the end state is a WhatsApp message with service, quantity, garment/product type, sizes, artwork status, deadline, and notes.

## Reference Takeaways, Not Copies

- **Pangram Pangram Foundry:** learn from type-led product confidence, restrained visual systems, clean product/value hierarchy, and high polish.
- **Simply Chocolate:** learn from tactile product storytelling and focused interaction, but do not make The Factory playful in the same way.
- **Protest Sportswear / Mammut:** learn from apparel/outdoor campaign energy, strong media, and product-context storytelling.
- **Nixon eCommerce Platform:** learn from merchandising clarity, product hierarchy, and robust commerce navigation.
- **Frans Hals Museum / MA:** learn from editorial-commerce blending and cultural confidence.
- **CSS Design Awards examples:** learn from UI/UX/innovation scoring discipline; do not add animation unless it improves use.

## The New Design Direction Claude Must Produce

Claude must propose and implement a design system that feels original. Required elements:

- A **Production Desk hero**: left side quote promise + MOQ + WhatsApp CTA; right side layered real video/poster with status chips and a production-ticket overlay.
- A **Services as production cards** section: printing, garment production, corporate uniforms, custom apparel, merch/souvenirs, caps/jackets. Each card has: what it is, what the client sends, MOQ reminder, and quote CTA.
- A **Process board**: enquiry -> artwork -> material/blank -> sample/proof -> bulk production -> quality check -> pickup/delivery.
- A **Proof wall**: masonry/rail/gallery using real downloaded Instagram media, grouped by production, people, product details, pop-ups/events, and team culture.
- A **Quote builder**: checkout-like form, sticky mobile CTA, WhatsApp message output, no fake payment.
- A **Visit panel**: address, appointment language, hours, map link, WhatsApp.
- A **Media control system**: video posters, muted autoplay, one-at-a-time audio, accessible mute/unmute.
- A **Mobile-first layout**: no compressed cards, no hidden CTA, no horizontal overflow, compact but premium spacing.
