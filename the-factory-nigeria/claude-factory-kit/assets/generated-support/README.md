# Generated Support Assets

This folder is reserved for optional GPT Images 2 or other AI-generated support visuals. Do not put fake portfolio work here.

Allowed: abstract textures, pattern-paper backgrounds, stitch/dashed-line graphics, blank production-ticket textures, neutral fabric/ink macros, and simple service icons.

Forbidden: fake photos of The Factory workspace, fake staff/customers, fake client logos, fake garment work, fake machinery, or anything that implies a real business claim.

If assets are generated, update `ASSET_MANIFEST.md` and label them as generated support assets.
