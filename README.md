# Brand Codebases

Two separate website codebases are set up here. They are intentionally independent so Lagos Sneaker Club and Bearded Genius do not share live copy, routes, assets, or Vercel settings.

## Folders

- `lagos-sneaker-club/` — the finished Lagos Sneaker Club ecommerce/culture site.
- `bearded-genius/` — the new Bearded Genius Nigerian-made streetwear ecommerce/culture site.

## Run Either Project

```bash
cd /Users/ayooluwakarim/brand-codebases/lagos-sneaker-club
npm run dev

cd /Users/ayooluwakarim/brand-codebases/bearded-genius
npm run dev
```

## Build Verification

Both projects have been installed and built successfully with `npm run build`.
